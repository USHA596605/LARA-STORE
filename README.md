
# LARA STORE - Amazon-Inspired E-Commerce Homepage

## 1. Project Description

LARA STORE is a frontend web development project inspired by the layout and shopping experience of an e-commerce website.

The project uses HTML, CSS, and JavaScript to create a shopping homepage with product cards, categories, a search bar, sorting options, and cart functionality.

This project is developed for educational purposes using an original store name and sample product information. It is not affiliated with Amazon.

## 2. Technologies Used

- HTML5 - To create the structure of the webpage.
- CSS3 - To style the webpage and create responsive layouts.
- JavaScript - To implement search, filtering, sorting, cart count, and other interactions.
- Flexbox - To arrange elements in flexible layouts.
- CSS Grid - To display product cards and category cards.
- Visual Studio Code - To write and manage the project code.

## 3. Project Features

### Header and Navigation
- LARA STORE brand name
- Delivery location
- Search bar
- Language option
- Account and orders sections
- Shopping cart
- Navigation links for shopping categories

### Hero Section
- Promotional banner
- Rotating promotional messages
- Shop Now button

### Category Section
- Electronics
- Fashion
- Home
- Beauty
- Mobiles
- Books
- Sports

### Product Section
- Minimum 12 product cards
- Product images
- Product names
- Customer ratings
- Current prices
- Original prices
- Discount information
- Add to Cart buttons

### JavaScript Functionality
- Search products by name
- Filter products by category
- Add products to the cart count
- Sort products by price
- Restore the default product order
- Open and close the category menu
- Automatically rotate hero banner messages
- Display a footer if one is not already present

### Responsive Design
The website uses CSS Grid, Flexbox, and media queries to adapt the layout to desktop, tablet, and mobile screens.

## 5. How to Run the Project

1. Install Visual Studio Code.
2. Open Visual Studio Code.
3. Select File > Open Folder.
4. Select the LARA STORE project folder.
5. Make sure index.html, style.css, and script.js are in the same folder.
6. Make sure the images folder contains the required product images.
7. Add the following line immediately before the closing body tag in index.html:

   ```html
   <script src="script.js"></script>
   ```

8. Save all files.
9. Open index.html in a web browser, or install the Live Server extension in Visual Studio Code.
10. If using Live Server, right-click index.html and select Open with Live Server.
11. Test the search, category filters, sorting, cart count, navigation menu, and hero banner.
